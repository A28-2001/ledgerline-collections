# Disclosure: what was prepared before Begin

Before pressing Begin, I prepared the plan and built a working version of the tool on made-up sample data: the Python pipeline (loader, customer matcher, verdict engine, an optional two-judge AI step), a Next.js app with its screens and two design rounds, a hour-one rehearsal with renamed columns, templates for this one-pager and the video, and research on existing collections and payment-matching products. None of that used Ledgerline's data room, because the files only open after Begin.

Everything that uses Ledgerline's data was done after Begin: the column mapping, the policy rules, the dispute finding, every rule from the conversation with the COO, the independent review of all 54 bills and the fixes it led to, and the video. The git history shows the timestamps of both.
